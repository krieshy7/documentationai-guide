## Get help

Both SDKs are open source under the MIT license. Bugs and feature requests go to the repository for the SDK you run.

<Columns cols={2}>
  <Card title="Python SDK issues" icon="bug" href="https://github.com/percepteye-ai/agent-flywheel/issues" horizontal>

  `agent-flywheel` on PyPI: `serve()`, `attach()`, the goose hook and the CLI.

  </Card>
  <Card title="Node plugin issues" icon="bug" href="https://github.com/percepteye-ai/agent-flywheel-node/issues" horizontal>

  `@percepteye/agent-flywheel` on npm: the OpenClaw and DeepSeek Harness plugin.

  </Card>
</Columns>

<Callout kind="alert">

Report security vulnerabilities privately to **security@percepteye.ai**, not in a public issue.

</Callout>

When you open an issue, include the SDK version (`pip show agent-flywheel`, or the `version` in the plugin's `package.json`), the exact refusal or log line, and which mode the agent runs in.
