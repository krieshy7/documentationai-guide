## Overview

PerceptEye AI requires an API token for all requests.

## Steps

1. Log in to `https://dashboard.percepteye.ai`
2. Go to **API Tokens** section
3. Click **Generate Token**
4. Copy your new token

## Usage Example

```bash
curl -H "Authorization: Bearer YOUR_API_TOKEN" https://api.percepteye.ai/v1/projects
```
